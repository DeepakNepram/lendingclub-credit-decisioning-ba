# Sprint 1 — Goal

> Scenario is hypothetical; all data is real LendingClub public data (2007–2018).

**Sprint goal:** A clean, documented, reproducible lending dataset with governed definitions, plus the
Executive Overview v1.

**Duration:** 2 weeks (simulated) · **Committed:** 28 story points
**Stories:** US-01, US-02, US-03, US-04, US-05, US-06 (E1 Data Foundation) + US-11 (E3 — Executive Overview v1)

The data foundation comes first because every later number — every KPI, every rule threshold, every
dashboard figure — depends on a trustworthy, reproducible dataset. Shipping the Executive Overview v1
in the same sprint gives the sponsor something tangible to react to early.
